## 🌠 Vision

**Code-To-Career** is not just an application; it is a meticulously engineered launchpad designed to transform early-stage developers into elite engineers. Designed with a stunning, high-fidelity **Dark AI-Lab aesthetic**, the platform employs real-time Generative AI, sophisticated state-machine tracking, and adaptive curriculum algorithms. It wraps advanced learning trajectories inside a deeply visceral, glassmorphism UI architecture that challenges and guides users based on their living performance data.

---

## ⚡ Core Features & Capabilities

### 1. 🤖 Zeno: The Omniscient AI Mentor
An embedded, highly-contextual AI Mentor orchestrates the learning experience. Powered by **Google Gemini Flash**, Zeno acts as an advanced pair-programmer and tutor:
- **Global Context Injection:** Zeno instantaneously processes your coding attempts, speech analysis scores, aptitude challenges, and active roadmaps into its system prompt dynamically.
- **Adaptive Interaction:** Rather than blind generic advice, Zeno provides precision guidance derived from an automatic *Skill Gap Analysis* running silently in the background on MongoDB.

### 2. 🗺️ AI-Generated Dynamic Roadmaps
A premium **CodeToCareer Learning Path Engine** dynamically generates custom curricula on the fly.
- **Hyper-Personalization:** Inputs such as targeted language (e.g., Python, C++, Next.js), learning methodology, current expertise level, and endgame goals are fused.
- **Milestone Tracking Map:** Granular, step-by-step UI checklists track progress alongside optimized web resources, syncing instantly via Zustand and MongoDB.

### 3. 🧪 The Hackathon Lab
A dedicated workspace for teams and solo developers aiming to crush rapid-prototyping events.
- **Lifecycle Management:** Guides users transparently through problem ideation, deep technical architecture generation, task breakdowns, to ultimate pitch preparation.
- **AI-Guided Architecture:** Harnessing LLM chains tightly structured sequentially, outputting production-ready blueprints. 

### 4. 📊 Multi-Faceted "Skill Gap" Engine
Real-time tracking natively embedded deeply across all learning parameters:
- **Coding Arena:** Tracks active algorithms mapped by difficulty and specific structural topics.
- **Speech/Interview Performance:** Automated telemetry processing verbal interviews.
- **Aptitude Processing:** Math and logic-based algorithmic testing.
*Mongoose aggregations unify these metrics into an exact mathematical profile to recommend the hardest required difficulty gaps exclusively.*

### 5. 💎 High-Fidelity Glassmorphic UI/UX
Designed to look indistinguishable from award-winning SaaS layers.
- **Next.js Turbopack UI:** Animated framer-motion hero screens with ambient mesh gradients and 3D glowing interaction states.
- **Unified Identity Dashboard:** Real-time optimistic UI sync layers allow continuous data management decoupled from heavy network requests.
- **OAuth Hybrid Auth Pipeline:** Polished, split-screen MongoDB-integrated authentication.

## 🚀 Architecture & Tech Stack

Code-To-Career is engineered precisely on scaling paradigms:

* **Frontend:** Next.js 16 (App Router), React, Tailwind CSS, Framer Motion, Lucide Icons.
* **Global State:** Zustand with Immer (mutability tracking) & optimistic sync updates.
* **Backend:** Next.js Serverless Edge Routes, heavily-typed TypeScript definitions.
* **Database:** MongoDB Native & Mongoose Aggregation pipelines running strictly structured Schemas (User, Hackathon Projects, Coding Attempts, Speech Attempts).
* **AI Pipelines:** Google Generative AI SDK (`gemini-3.6-flash`, structured text extraction).
* **Auth:** NextAuth (Server-Session & JWT Strategy).

## 🔥 Getting Started

### Prerequisites
- Node.js `v18.x` or later.
- MongoDB Server / Atlas connection URI.
- Google Gemini API Key.

### Installation
1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables inside `.env.local`:
   ```bash
   MONGODB_URI=your_mongodb_cluster_string
   NEXTAUTH_SECRET=your_auth_secret
   GEMINI_API_KEY=your_gemini_key
   ```

3. Spin up the Turbopack dev pipeline:
   ```bash
   npm run dev
   ```

Explore the bounds of the learning engine at `http://localhost:3000`.
